What makes it different

Design choices grounded in what plans get wrong.

💧

Humidity counts

Hourly WBGT, the occupational heat-stress standard — not just the day's maximum temperature.

⏱️

Instructions, not alarms

“30 min work, 30 min rest, 12–4 PM”, from ACGIH work–rest limits.

✅

Accountable by design

Every action has an owner, a Done button and a public timestamp.

📡

Plugs into India's systems

CAP 1.2 alerts, the format SACHET ingests. Any city's plan is a config file.
